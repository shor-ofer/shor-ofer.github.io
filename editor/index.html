The first level in the list is where the level pack starts. Where each flag leads is set on the flag. Clear empties this level, Delete takes it out of the level pack; both ask first.
Keys 1 2 3. The board shows all three as the game will. Only Mid collides.
Keys P E S. Drag to paint; right-drag always erases; Ctrl+click picks up what a cell holds. The finish is the F flag in the object palette. Shift-drag selects cells; a click inside fills them all with what is picked (a right-click empties them): Ctrl+C copies them, Ctrl+X cuts. Ctrl+V puts the whole copy down at the mouse — or, with cells selected, fills them with the copy repeated; Ctrl+Shift+V pastes the layer you are on only. With Shift, copy, cut and Delete also work on the current layer only. While the copy's outline follows the mouse, Ctrl+C, Ctrl+X and Delete act on the cells under it. Delete empties the selection, Esc lets it go.
