Sprites

Frames

A part is a named run of frames — an object's class picks one by name, like a plant's bud. Click a frame to pick it, Ctrl+click for several; drag frames between parts, double-click one to paint it. Ctrl+C copies the picked frames and Ctrl+V adds them to the part under the pointer — pixels copied in the pixel editor or the Tiles tab paste in as a new frame, and a copied frame pastes into the pixel editor as pixels.

Objects

Object

Looks like

An object is what a level places: one of the game's classes, the codes a map block names it by, and a value for each property the class reads. Its look is a sprite, made on the Sprites tab.

Terrain sheet

A row per kind of tile and a column per colour, 0 to 9. A map block names a tile by its row and column, so row 1# column 1 is 1#1. The button beside each row says what it collides as.

No sheet loaded

Click a tile to paint it. Over a tile, Ctrl+C copies it and Ctrl+V pastes onto it; Ctrl+Shift+V fills the whole row, each column recoloured to its own colour.

Sheet

Backgrounds

Tiling sprites a level can sit in front of. Transparent art works best — the level's own colour shows through, so one sheet suits several moods.
